Для хранения биометрии клиентов была создана отдельная бд. Для получения данных биометрии
создается ключ-токен через новый сервис токенайзер чтобы при утечки данных нельзя было сопоставить персональные данные
с биометриеей клиентов. Сервера для управления шлагбаумом и домофонами представляет другая компания.
Весь обмен информацией между сторонней компаний и нашими серверами происходит через https соединения с токеном
доступа. Авторизация и аутентификация происходит благодаря выданному токену доступа на каждый дом.
Управление шлагбаумом и домофоном происходит через сервис компании представителя услуг.
